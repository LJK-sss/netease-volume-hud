# 网易云音量 HUD · 使用说明（v1.4）

> 一个 196×50 的小条，只控制网易云音乐这一路音量，并自动把每首歌的响度维持在你能接受的区间内。

---

## 一、它是什么

| 项 | 说明 |
|---|---|
| 形态 | 单文件 `NeteaseVolumeHUD.exe`（约 330 KB） |
| 运行时 | .NET Framework 4.8（Windows 自带） |
| 依赖 | 无。不需要安装、不需要管理员权限 |
| 作用范围 | **只改网易云音乐这一条音频会话**，不碰系统音量、不碰游戏 |

---

## 二、界面

| 项 | 规格 |
|---|---|
| 常态尺寸 | 196×50（150% 缩放 → 294×75） |
| 悬停尺寸 | 196×76（只增高，不向右扩展，避免出屏） |
| 材质 | 分层窗口逐像素透明 + 圆角 + 88% 不透明度，能透出背后的画面 |
| 常态内容 | 红橙渐变音符圆 · 大号百分比 · 进度条 · **右侧实时响度读数** |
| 悬停追加 | 曲目名（**占满顶部整条，从图标正上方开始**；ClearType 渲染；过长时自动缓慢滚动）+ 菜单图标 + ×（退出） |
| 行为 | **置顶**，但每 **15 秒**才重申一次（这样微信/QQ 截图时不会频繁跳出挡住画面）；**永不抢焦点**（点它不会把游戏切后台） |

## 三、操作

| 操作 | 作用 |
|---|---|
| 拖左侧音符圆 | 移动窗口 |
| 右键拖任意处 | 移动窗口（备用） |

## 四、音量控制范围

```
网易云内部滑块（你自己设，建议 100%）
      ↓
★ 网易云这条音频会话的音量  ← 本工具只动这一层
      ↓
系统总音量（影响所有程序）      ← 完全不碰
```

- 通过 WASAPI 定位 `cloudmusic.exe` 的音频会话
- **优先绑定「默认输出设备 + 活动状态」**，插拔耳机后自动重绑并恢复本曲音量
- 不注入、不联网、不读你的音乐文件

## 五、调整策略（核心）

### 5.1 目标区间

```
            容差 ±1.5              容差 ±1.5
   ────────────┬─────────────────────┬──────────
            −28.5                  −27                 −25.5
               ← 太安静：升 →    │    ← 太响：降 →
                               中心（最舒适）
```

- **中心** = 参数里的「基准响度」
- **区间** = 中心 ± 「容差」
- **落在区间内：完全不动**
- 升的上限是「基准音量」（40%）

### 5.2 学习器（主力）

| 环节 | 规则 |
|---|---|
| 采样 | 每 100ms 取一个 RMS 样本，**低于 −60 dBFS 直接丢弃** |
| 归一化 | 源响度 = 样本 dB − 20·log10(当前推子)，与音量无关 |
| 依据 | **近 45 秒窗口的 P80 分位**（不被长安静段骗） |
| 首次定档 | 攒够「测量时长 × 10」个样本后**一次到位**（粗调） |
| 后续微调 | **每 6 秒**复检；跑出区间就调，**每次最多 1 dB**，可升可降，次数不限 |
| 上限 | 永远不超过「基准音量」 |

> 可以想成「每 6 秒看一眼，偏了就挪 1 dB」，所以被压过头的歌会一点点升回来，不会卡死。

### 5.3 限幅器（只管局部爆音）

| 项 | 值 |
|---|---|
| 检测电平 | 约 **1.2 秒**的平均电平（不跟乐句起伏） |
| 门限 | 基准响度 + 限幅余量（例：−27 + 4 = **−23 dB**） |
| 触发 | 持续超过门限 **+1 dB** |
| 动作 | 压到门限（单次最多 −12 dB），**保持 3 秒** |
| 释放 | 每秒放开 1.5 dB |
| 是否写缓存 | **否**（纯临时保护） |

### 5.4 限幅反馈（一次性粗调）

30 秒内累计 3 次**独立**限幅（1.5 秒内不重复计）说明「这首歌被估低了」：

```
修正源响度 += 平均超出量 → 写回缓存 → 重置限幅
```

- **每首歌只允许一次**
- 必须已完成定档
- 修正后 20 秒冷却
- 这是解决「卡在门限、到不了目标」的关键

### 5.5 手动接管

你手动改过音量（点条子 / 拖动 / Ctrl+↑↓）之后：

- 本曲**不再自动改音量**（你的选择优先）
- 但**继续测量、继续写缓存**，下次播放用的是自动学到的值

## 六、参数面板

悬停后**左键点「菜单图标」**打开，从图标左上方弹出，鼠标离开自动收起。

| 参数 | 默认 | 范围 | 步长 | 调大 → | 调小 → |
|---|---|---|---|---|---|
| 基准音量 | 40% | 25~70% | ±5% | 安静歌更响（硬上限） | 整体上限更低 |
| 基准响度 | −26 dB | −30~−14 | ±1 dB | 更响 | 更轻（响歌压得更狠） |
| 容差 | ±1.5 dB | ±0.5~±4 | ±0.5 | 更宽松、动作更少 | 更贴目标、动作更多 |
| 测量时长 | 12 秒 | 4~12 秒 | ±2 秒 | 首次定档更准、更慢 | 定档更快、易被前奏误导 |
| 限幅余量 | 4 dB | 2~8 dB | ±1 dB | 只有特别炸才压 | 更容易被压（更安静） |
| 自动增益 | 开 | 开/关 | 整行点 | — | — |
| 恢复默认参数 | — | — | 整行按钮 | — | — |

> **经验关系**：限幅余量应比容差大 2~3 dB，否则限幅器会落进区间内部，导致持续压制。

## 八、记忆与学习

### 缓存里存什么

`songs.ini` 每行：`源响度dB|歌名`，例如 `-13.70|Pushing Me Away - Linkin Park`

**存的是「这首歌本身有多响」，与基准、容差、限幅余量全部无关。** 所以改参数不需要重新学习，套用时实时重算。

### 什么时候更新 / 落盘

| 时机 | 行为 |
|---|---|
| 首次定档、每次微调、限幅反馈 | 更新**内存**里的缓存 |
| 切歌 / 正常退出 | 写入磁盘 |
| 被强杀 | 本次的内存修正丢失 |

### 脏数据会被自动纠正

播放时学习器会重新测量，发现偏离就用「微调」一步步改回来（**1 dB / 6 秒**），同时更新缓存。偏差 10 dB 大约需要 1 分钟。

### 手动清空缓存

删除 `%APPDATA%\NeteaseVolumeHUD\songs.ini` 即可，下次播放全部重新学习。

## 九、文件位置

```
%APPDATA%\NeteaseVolumeHUD\
    config.ini    所有参数、窗口位置、界面大小/透明度
    log.txt       运行日志（切歌、定档、微调、限幅、参数变更）
    songs.ini     按歌缓存
```

- `log.txt`：每次启动会清空重写；单次运行中**超过 1 MB 自动清空**（首行留一条"已自动清空"的记录）。日志只含歌名和 dB 数字，不含音频、不含个人信息，随时可删。
- 如果程序是从某些受限环境启动（例如被测工具拉起），`%APPDATA%` 写不进去时会**自动退回到 exe 同级目录**建这三个文件。

> 如果 `%APPDATA%` 不可写，会自动退回到 exe 同级目录。

**config.ini 字段一览**

| 键 | 含义 |
|---|---|
| `x` / `y` / `monitor` | 窗口位置（含显示器） |
| `scale` / `opacity` | 界面大小、不透明度 |
| `defaultVolume` | 基准音量（%） |
| `targetDb` / `toleranceDb` | 目标中心 / 区间半宽 |
| `measureSeconds` | 测量时长（秒） |
| `limitMarginDb` | 限幅余量 |
| `autoGain` | 自动增益开关 |
| `autoStart` | 开机自启 |
| `resetOnSongChange` | 关闭自动增益时，切歌是否回到基准 |

## 十、稳定性与已知限制

**已做的保护**

- **单实例**：再运行一次 exe 会把已有窗口叫到最前，不会开第二个
- **设备自愈**：换输出设备后重绑并恢复本曲音量，过渡期 600ms 不采样
- **过渡保护**：每次改音量后 350ms 内不采样，避免电平错位污染估计
- **切歌清窗**：切歌时同时清空整首缓冲与 45 秒窗口，避免上一首的样本污染新歌
- 内存约 45 MB，一个抓流线程 + 三个轻量定时器

**明确的限制**

| 不做 / 做不到 | 原因 |
|---|---|
| 盖住**独占全屏**游戏 | Windows 限制，只有注入能破 |
| 音量超过 100% | 会话推子物理上限 |
| 读写网易云内部滑块 | 自绘 UI，无障碍树拿不到 |
| 全局热键 | 会抢占其它软件组合键；现在是「悬停时才注册」 |
| 标准 LUFS 响度 | 目前用 RMS 的 P80 近似，同一读数下「响」与「吵」不完全等价 |
| 托盘图标 | 本机环境不接受托盘注册，已整体移除 |

## 十一、常见问题

**Q：切歌后音量半天不动？**
在区间内就不动。若这首歌没被定档，检查「测量时长」是否大于这首歌的有效音频长度。

**Q：某首歌被压得很低？**
看日志里 `源=` 的值（越负越安静，越接近 0 越响）。同一首歌不同次播放若差别很大，说明缓存被学习更新过，属于正常。

**Q：读数为什么一直在变？**
读数是**近 45 秒**的响度，跟着音乐密度走，不是整首平均。

**Q：窗口不见了？**
再运行一次 exe 会把它叫到最前。

**Q：改了参数要重新学吗？**
不用。缓存存的是源响度，参数变化会实时重算。

**Q：想让它更安静 / 更响？**
优先调「基准响度」（整体平移）；只想治个别爆音就调小「限幅余量」。

**Q：右键菜单为什么不弹？**
必须右键点在小窗右侧的**菜单图标**上，点条子其它位置不会弹（那里是拖动区）。

```
    Native.cs       Win32 互操作

```

编译（在 `src` 目录）：

```
csc /nologo /target:winexe /platform:x64 /unsafe /optimize+ /win32icon:app.ico ^
    /out:..\NeteaseVolumeHUD.exe ^
    /r:System.dll /r:System.Drawing.dll /r:System.Windows.Forms.dll /r:System.Core.dll *.cs
```

> 重建前必须先结束进程并删除旧 exe，否则会报 CS0016。
> 旧版本备份在 `backup-v1.3-仅降不升\`，内含可回退的 exe 与源码。
